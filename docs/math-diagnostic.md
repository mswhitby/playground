# Classroom math starting-point diagnostic, v1

Authoring source: `content/diagnostic-v1.json`. Playground includes a reviewed snapshot of the same file. Questions and examples are original. This is an instructional screener, not a validated TSIA2 assessment or official placement score.

Allow roughly 25–35 minutes and scratch paper. Students work independently and mark Not sure rather than guess when they have no strategy. Honor accommodations and record tools used when interpreting the result. Four questions each sample number foundations, ratios/percents, linear algebra, nonlinear algebra, geometry, and statistics/probability. There are no hints until submission.

For each skill, 0–2 correct suggests guided prep; 3–4 suggests a deeper teacher check, not mastery. Four Not sure responses mean evidence is insufficient and a teacher check is needed. Skips remain visible. Review written reasoning and two new problems before assigning a level. Start with number foundations if that skill needs work, then address the other flagged groups. Never use the overall score alone to place a student.

The plan includes an introductory worked example for every group. Published Week 1 lessons support percents (Day 1), equations (Day 2), slope (Day 3), and model comparisons (Day 4). Other groups need teacher-provided practice; the screen explicitly identifies these gaps. Prioritize writing full foundations, nonlinear algebra, geometry, and statistics lessons next.

Browser storage retains first and latest attempts, not a teacher roster record. Students download JSON results and share them through the teacher's established submission channel. No diagnostic is automatically graded or sent to an account. A retry uses the same items and is practice; use fresh questions for evidence of growth. Pilot with one class, inspect item misunderstandings, and revise the version before wider use.
